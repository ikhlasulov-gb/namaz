Prayer times, Qibla and the Hijri calendar.

Namaz is a native Linux app for Muslim prayer times. A Rust prayer engine and a calm Qt 6 interface, with a full-screen Masjid mode, adhan reminders and no account, tracking or cloud.

Install with Flatpak View the source

GPL-3.0-or-later · Rust + Qt 6 · English, Русский, Bahasa Indonesia

What is inside

A focused app for the everyday routine — not a dashboard full of things you never use.

Accurate prayer times

Six calculation methods, Standard or Hanafi Asr, high-latitude rules and per-prayer adjustments.

Qibla compass

A true-bearing compass that stays readable in light and dark themes.

Adhan and reminders

Bundled CC0 recordings, iqama, before/after reminders and custom audio folders.

Hijri calendar

Day, month and year views with a Gregorian/Hijri offset and PDF or CSV export.

Masjid screen

A frameless full-screen clock with the next prayer and today's times for a mosque display.

Private by default

Everything runs offline. No accounts, telemetry or network requests for prayer calculations.

Install

The Flatpak is the recommended way to install and update Namaz.

Flatpak

Add the signed repository once and install the app:

flatpak remote-add --if-not-exists --user namaz \
  https://ikhlasulov-gb.github.io/namaz/namaz.flatpakrepo
flatpak install --user namaz io.github.ikhlasulov_gb.Namaz

Run it with flatpak run io.github.ikhlasulov_gb.Namaz. Updates arrive through flatpak update or your software centre.
