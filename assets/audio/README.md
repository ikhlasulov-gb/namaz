# Bundled audio

Namaz ships a small audio set:

| File | Purpose | Credit |
| --- | --- | --- |
| `ADHAN.ogg` | Built-in adhan for all prayers | Ahmad bin Abdul-Aziz Al-Nufais |
| `BISMILLAH.ogg` | Startup / Bismillah sound | Mishary Rashid Alafasy |
| `ALIHLAS.ogg` | Short surah for the Quran menu | Mishary Rashid Alafasy |

The recordings are freely available and may be used by anyone; the reciters
did not state a licence.  See [`audio.LICENSE`](audio.LICENSE).

Users can add their own adhan, dua, iqama and Quran recordings in
**Preferences → Audio**.  Custom files and folders accept WAV, OGG, MP3 and
FLAC.
