# Bundled audio

Namaz ships a small, freely licensed audio set:

| File | Purpose |
| --- | --- |
| `ADHAN.ogg` | Built-in adhan for all prayers |
| `BISMILLAH.ogg` | Startup / Bismillah sound |
| `ALIHLAS.ogg` | Short surah for the Quran menu |

All three recordings are CC0, author **Ikhlasulov**.  See [`audio.LICENSE`](audio.LICENSE).

Users can add their own adhan, dua, iqama and Quran recordings in
**Preferences → Audio**.  Custom files and folders accept WAV, OGG, MP3 and
FLAC.
